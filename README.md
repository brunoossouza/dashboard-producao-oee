# 📊 Dashboard de Produção - OEE (Eficiência Global)

### 📌 Sobre o projeto
Este dashboard foi desenvolvido para o monitoramento e análise de performance industrial. O foco principal é o cálculo do **OEE (Overall Equipment Effectiveness)**, permitindo uma visão clara sobre o quanto a linha de produção está sendo eficiente em relação à sua capacidade teórica.

---

### 🚀 Tecnologias Utilizadas
* **Power BI**: Construção dos dashboards e visualização.
* **DAX**: Criação de medidas complexas para cálculo de eficiência e produtividade.
* **Power Query**: Tratamento e limpeza dos dados de produção.
* **Excel/SQL**: Fonte de dados dos registros de produção e paradas.

---

### 🎯 Indicadores Principais (KPIs)
O painel monitora os três pilares fundamentais do OEE:

1. **Disponibilidade**: Percentual de tempo que a máquina esteve produzindo em relação ao tempo planejado.
2. **Produtividade (Performance)**: Comparação entre a quantidade produzida real vs. a capacidade teórica da máquina.
3. **Qualidade**: Percentual de itens aprovados em relação ao total produzido (descontando itens rejeitados).

**Outras métricas monitoradas:**
* **Qtd Produzida**: 3,1 Mi de unidades.
* **Qtd Rejeitada**: 21,1 Mil unidades.
* **Horas Paradas**: 8,9 Mil horas (foco em redução de gargalos).

### 🛠️ Como utilizar
O dashboard é interativo. É possível filtrar as análises por:
* **Mês**: Acompanhamento da evolução temporal do OEE.
* **Linha de Produção**: (Se aplicável) Comparação de eficiência entre diferentes setores.
* **Motivo de Parada**: Identificação rápida das causas de indisponibilidade.
